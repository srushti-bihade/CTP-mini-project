# 🧠 Memory Rush

### A Fast-Paced Memory Sequence Game Built with Python & Pygame

**Memory Rush** is a fullscreen memory game built using **Python and Pygame**.

The game challenges players to memorize a sequence of numbers and enter the sequence correctly before the timer runs out. As the player progresses, the sequence becomes longer, making each level more challenging.

---

## 🎮 Game Overview

Memory Rush tests the player's:

- 🧠 Memory
- ⚡ Concentration
- 🎯 Accuracy
- ⏱️ Speed
- 🔢 Number recall

The player starts with a short number sequence. The sequence is displayed briefly, after which the player must remember and enter it correctly.

Correct answers allow the player to progress to the next level, while incorrect answers or running out of time costs a life.
